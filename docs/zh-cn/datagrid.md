# DataGrid 表格控件

#### 资源键代码：  
`{StaticResource {x:Static pu:StyleKeys.DataGridStyle}}`  

#### 辅助类：  
_Panuon.WPF.UI.DataGridHelper_  

#### 依赖于：  
*<pu:StyleDictionary Includes="DataGrid">* 或 *<pu:KeyOnlyStyleDictionary Includes="DataGrid">*  

#### 实际资源字典：  
*pack://application:,,,/Panuon.WPF.UI;component/Styles/DataGrid.xaml* 或 *pack://application:,,,/Panuon.WPF.UI;component/Styles/DataGridStyle.xaml*

---

## 小提示
1. 当输入框被禁用时，`Opacity`的属性值将与*GlobalSettings.Setting.DisabledOpacity*属性的值绑定（默认为`0.4`）。有关全局设置的更多内容, 请查看[*GlobalSettings 全局设置*]()。  
2. 默认情况下，`WatermarkForeground`会与`Foreground`属性绑定，并通过转换器转换成更浅的颜色。如果将`Foreground`设置为渐变色，则转换不会生效，占位符的。

```xml
<DataGrid
    Width="400"
    Height="250"
    pu:DataGridHelper.ColumnHeaderBackground="#ffffff"
    pu:DataGridHelper.ColumnHeaderSeparatorBrush="#ffffff"

    pu:DataGridHelper.RowSelectedBackground="#36AAF7"
    pu:DataGridHelper.RowSelectedForeground="#ffffff"
    AutoGenerateColumns="False"
    Background="#ffffff"
    BorderThickness="2"
    CanUserAddRows="False"
    FontSize="20"
    ForceCursor="True"
    GridLinesVisibility="All"
    HorizontalGridLinesBrush="White"
    ItemsSource="{Binding items, RelativeSource={RelativeSource AncestorType=Window}}"
    RowHeight="40"
     VerticalGridLinesBrush="#ffffff">
        <DataGrid.Columns>
            <DataGridTextColumn
                Width="*"
                Binding="{Binding Id}"
                Header="Id" />
            <DataGridTextColumn
                Width="*"
                Binding="{Binding Name}"
                Header="Name" />
            <DataGridTextColumn
                Width="*"
                Binding="{Binding Age}"
                Header="Age" />
        </DataGrid.Columns>
</DataGrid>
```

```xml
public MainWindow()
{
    InitializeComponent();
    items = new List<Item>()
    {
        new Item { Id = 001, Name = "Tom",Age =12 },
        new Item { Id = 002, Name = "Lucy",Age =11 },
        new Item { Id = 003, Name = "Derek",Age =12 },
        new Item { Id = 004, Name = "Lily",Age =11 },
        new Item { Id = 005, Name = "Jack",Age =11 }
    };
}
public List<Item> items { get; set; }
public class Item
{
    public int Id { get; set; }
    public string Name { get; set; }
    public int Age { get; set; }
}
```

## 内部资源键

### ClearButtonStyle
`{StaticResource {x:Static pu:PasswordBoxHelper.ClearButtonStyleKey}}`  
控件类型：Button 按钮
清空按钮的样式。  

示例：
```xml
<!--修改清空按钮的图标-->
<PasswordBox>
    <pu:PasswordBoxHelper.ClearButtonStyle>
         <Style BasedOn="{StaticResource {x:Static pu:PasswordBoxHelper.ClearButtonStyleKey}}" TargetType="Button">
             <Setter Property="Content" Value="&#xe933;" />
         </Style>
    </pu:PasswordBoxHelper.ClearButtonStyle>
</PasswordBox>
```
